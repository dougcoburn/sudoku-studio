How hints are ranked
  1. Novice: row alone → column alone → 3 × 3 box alone.
  2. Beginner: two regions → all three → earlier eliminations → hidden singles.
  3. Intermediate: locked candidates → naked pairs → hidden pairs.
  4. Advanced: naked triples → hidden triples → X-Wing.
  5. Expert: XY-Wing → Swordfish.

The easiest available rule anywhere in the grid comes first. These are teaching ranks, not a rating of the whole puzzle. A stalled search never presents a guessed value as a deduction.
